# Code of Conduct

This code of conduct is adapted from the [Contributor Covenant][cc], version
2.1. It is a condensed adaptation, not the Covenant text verbatim — where the
two differ, the Covenant is the fuller statement of the same intent.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct.html

## Our Pledge

We pledge to make participation in this project a respectful experience for
everyone, regardless of background, identity, experience level, or viewpoint.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and technical tradeoffs.
- Give and accept constructive feedback.
- Focus criticism on the work, not the person.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Publishing private information without permission.
- Sexualized language or imagery.
- Sustained disruption of project discussions.

## Enforcement

Report conduct concerns to `support@nrouter.ai`. Maintainers may remove
comments, close issues, block users, or take other reasonable action to protect
the project community.

If a report concerns a maintainer, say so in the subject line so it is not
routed back to the person it is about.
