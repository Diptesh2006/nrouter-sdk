# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a respectful experience for
everyone, regardless of background, identity, experience level, or viewpoint.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect differing viewpoints and technical tradeoffs.
- Give and accept constructive feedback.
- Focus criticism on the work, not the person.

## Unacceptable Behavior

- Harassment, threats, insults, or personal attacks.
- Publishing private information without permission.
- Sexualized language or imagery.
- Sustained disruption of project discussions.

## Enforcement

Report conduct concerns to `hello@nrouter.ai`. Maintainers may remove comments,
close issues, block users, or take other reasonable action to protect the
project community.
