# Approved logo assets

This package contains byte-for-byte copies of the official nRouter wordmarks from
`nRouterGateway/nrouter-frontend-ui` revision `88eb78498cce51edd1d7d6fd9110f48a0f2919be`:

- `nrouter-wordmark-light.svg` — used on dark product screens.
- `nrouter-wordmark-dark.svg` — used on light product screens.

These are deterministic post-production overlays, not inputs to an image or video model. Do not
derive them from screenshots, redraw them, or substitute a remote website URL. The canonical
source paths and SHA-256 hashes are in `../brand-assets.json`.
